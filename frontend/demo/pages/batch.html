Batch page

Commit many encrypted vote packages as one batch.

V3 verifies every unified Groth16 proof off-chain, enforces one active eligibility root, checks nullifier continuity, creates inclusion receipts, and commits the exact encrypted aggregate.

Simulation boundary: the per-vote proofs are real, but the final batch commitment is not trustless until recursive proof aggregation also proves the nullifier-state transition on-chain.

Commands

npm run build:batch -- batch-input.json
npm run build:batch:v2 -- batch-input.json batch-artifact.json
npm run build:batch:v3 -- batch-input.json batch-artifact-v3.json
npm run check:data -- batch-input.json

Failure demonstrations

  • !duplicate nullifier rejected
  • !nullifier-root discontinuity rejected
  • !missing local/IPFS package rejected
  • !invalid Groth16 ballot proof rejected
  • !stale eligibility root rejected
