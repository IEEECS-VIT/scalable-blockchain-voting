Receipt page

Give the voter a private inclusion receipt.

The receipt proves a vote package was included in a batch manifest using a Merkle proof, without revealing the selected candidate.

Failure demonstration: if the package digest or Merkle sibling changes, receipt verification fails against the committed CID Merkle root. Full proof-system receipt verification is still pending real batch validity proofs.

Receipt contains

  • ✓batchManifestDigest
  • ✓packageDigest and leafHash
  • ✓Merkle proof path
