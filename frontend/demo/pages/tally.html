Tally page

Aggregate encrypted ballots, then decrypt through trustee shares.

The local pipeline aggregates accepted encrypted ballots, verifies DLEQ-style decryption share proofs, and builds result/public-input hashes for the future tally verifier.

Simulation boundary: local DLEQ checks are not an audited threshold ceremony or an on-chain tally SNARK.

Commands

npm run build:tally -- tally-input.json
npm run build:tally-result -- tally-result-input.json
