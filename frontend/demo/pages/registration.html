Registration page

Bind anonymous eligibility to one ephemeral voting key.

The voter creates an election-scoped identity nullifier and ephemeral voting key. A relayer submits the registration request so the voter’s identifiable wallet does not directly publish the credential binding.

Simulation boundary: this page expects a real anonymous eligibility proof later. The current fixture uses placeholder proof bytes and is not an Anon Aadhaar proof.

Inputs

  • ✓electionId and identityNullifier
  • ✓ephemeral votingKey
  • !real Anon Aadhaar proof pending

Relayer artifact

npm run build:registration-request -- registration-request-input.json

Output includes publicInputsHash and registerWithProof calldata for a dedicated relayer account.
